# Численный снимок основного поискового этапа

**Назначение:** данные для чтения и проверки опубликованного разбора без моделей.
**Статус:** завершённый поиск, снимок от 25 октября 2026 года; подтверждающих
экспериментов в этом наборе нет. Контекст — [RESULTS.md](../../RESULTS.md),
формулы и обозначения — [METHODOLOGY.md](../../METHODOLOGY.md).

Источник — локальный анализ результатов `results_search` по фиксированному
плану `configs/main_search_v1.json`. Выполнены 1 620 позиций, пропусков нет,
различных условий с учётом seed — 1 080. Пять seed одной конфигурации не становятся
дополнительными независимыми наблюдениями из-за повторных контролей в разных сериях.

Шесть полных таблиц скопированы из анализа с сохранением значений и структуры.
baseline_runs.csv содержит только baseline-строки runs.csv; абсолютные пути
рабочей машины удалены. Опубликованные CSV/JSON имеют UTF-8 и окончания строк LF,
закреплённые в .gitattributes, чтобы контрольные суммы не менялись при клонировании
на другой ОС. У чисел сохранена десятичная точка. Пустые значения не следует заменять нулями.

Ключевые рисунки находятся в [figures/main_search_v1](../../figures/main_search_v1/)
в форматах PNG и PDF. `figure_sources` в snapshot.json сопоставляет их короткие имена
исходным именам автоматического анализа. Английские подписи соответствуют определениям
русскоязычной методики; greedy в исходных данных обозначает deterministic-оценку.

## Происхождение и целостность

snapshot.json фиксирует SHA-256 кода анализа, отдельный идентификатор обучения,
версии библиотек, параметры bootstrap, покрытие плана и SHA-256 опубликованных
таблиц и рисунков. Пути в sha256 заданы относительно корня репозитория.
Сам snapshot.json и тексты Markdown в список контрольных сумм не входят.
plan_sha256 — контрольная сумма содержимого определения плана, не SHA-256 байтов
JSON-файла. Она проверяется штатным загрузчиком плана и не зависит от окончаний строк.

При обновлении документации все девять численных таблиц исходного анализа
остались побитово одинаковыми; идентификатор обучения не изменился. Исправлены
только формулировки автоматического отчёта и подписей рисунков.
Контрольные суммы помогают проверить целостность снимка, но не заменяют исходные
данные, независимое повторение или подтверждающие эксперименты.

## Границы воспроизводимости

Это производные таблицы и выбранные рисунки, а не полный архив исследования.
Здесь нет всех кривых, поэпизодных оценок, обученных моделей и файлов каждого запуска.
Полный опубликованный архив исходных результатов пока не предоставлен.
Для повторного анализа нужен локальный `results_search`, полученный отдельно либо
повторным обучением по [основному протоколу](../../MAIN_STUDY.md).

Команда analyze обновляет локальный `analysis_main_search`, но не этот снимок
и не содержательный разбор автоматически. При новой публикации следует обновлять
тексты, выбранные таблицы, рисунки и snapshot.json согласованно. Подтверждающую
фазу нельзя добавлять к поисковой выборке без отдельного обозначения и анализа.
